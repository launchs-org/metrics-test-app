# K8s メトリクス デバッグツール

Kubernetes のメトリクスサーバー動作確認・負荷テスト用の Web アプリケーションです。

---

## ⚠️ 重要な警告 — 本番環境への展開は絶対に禁止

このツールは **開発・検証環境専用** です。以下の理由から、**本番クラスターへのデプロイは絶対に行わないでください。**

| リスク | 詳細 |
|--------|------|
| **機密情報の漏洩** | 環境変数一覧を認証なしで誰でも閲覧できます。API キー・DB パスワード・シークレット等が丸見えになります。 |
| **ファイルシステムの露出** | ルート (`/`) からディレクトリツリーを自由に閲覧できます。コンテナ内の設定ファイル・証明書・マウントされた Secret が参照可能です。 |
| **意図的なサービス停止** | CPU・メモリを任意の割合で消費できるため、Pod やノードをリソース枯渇させることができます（DoS）。 |
| **認証機能なし** | アクセス制御が一切実装されていません。ネットワークに到達できれば誰でも全機能を利用できます。 |

> **このツールを本番環境で発見した場合は、直ちに該当 Pod を削除し、環境変数に含まれるシークレットをすべてローテーションしてください。**

## 機能一覧

| タブ | 機能 |
|------|------|
| **システム情報** | CPU コア数・モデル名、メモリ合計/使用中/空き容量、CPU/メモリ使用率、Go バージョン、OS、ホスト名 |
| **ストレステスト** | 指定割合 (1〜100%) の CPU 負荷、指定容量 (1〜2048 MB) のメモリ確保。開始・停止をリアルタイム制御 |
| **環境変数** | コンテナに設定された全環境変数の一覧。キー・値でのインクリメンタル検索付き |
| **ディレクトリ** | ルート (`/`) からのファイルシステム探索。パンくずナビゲーション付き |

## 起動方法

### ローカル実行

```bash
go run .
# デフォルトポート: 8081
# http://localhost:8081
```

ポートを変更する場合:

```bash
PORT=9090 go run .
```

### Docker

```bash
docker build -t k8s-debug-tool .
docker run --rm -p 8081:8081 k8s-debug-tool
```

### Kubernetes（開発環境のみ）

```bash
# Deployment を適用
kubectl apply -f k8s/

# ポートフォワードでアクセス
kubectl port-forward svc/k8s-debug-tool 8081:8081

# 確認が終わったら必ず削除する
kubectl delete -f k8s/
```

## API エンドポイント

| メソッド | パス | 説明 |
|----------|------|------|
| `GET` | `/api/sysinfo` | CPU・メモリ情報を JSON で返す |
| `GET` | `/api/env` | 環境変数一覧を JSON で返す |
| `GET` | `/api/workdir` | 作業ディレクトリを返す |
| `GET` | `/api/dir?path=/` | 指定パスのディレクトリ一覧を返す |
| `GET` | `/api/stress/status` | ストレス実行状態を返す |
| `POST` | `/api/stress/cpu/start` | CPU ストレス開始 `{"percent": 50}` |
| `POST` | `/api/stress/cpu/stop` | CPU ストレス停止 |
| `POST` | `/api/stress/mem/start` | メモリ確保開始 `{"mb": 256}` |
| `POST` | `/api/stress/mem/stop` | メモリ解放 |

│       └── stress.go           # ストレス状態管理・CPU/Mem ワーカー
